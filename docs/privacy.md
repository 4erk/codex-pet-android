# Privacy

Codex Pet обрабатывает состояние питомца и уведомления ChatGPT локально. Сеть используется отдельно и только для проверки и загрузки обновлений из публичных GitHub Releases.

## Что обрабатывается локально

Только уведомления от настроенного приложения-источника. Для текущего списка задач заголовок, краткий текст и `PendingIntent` находятся в оперативной памяти процесса.

На диск сохраняются:

- настройки питомца, реплик, анимаций и обновлений;
- размер и позиции;
- кэшированный питомец / импортированный набор питомца;
- хэш питомца, время обновления и технические сведения об источнике;
- временный APK обновления во внутреннем кэше приложения до установки или очистки кэша.

История переписки и задач на диск не сохраняется.

## Диагностика

Стабильная сборка не сохраняет полный текст уведомлений в диагностических снимках: только наличие и длину известных полей.

Тестовая сборка может показывать полный текст на отдельном экране диагностики. Эти значения:

- не пишутся в Android log;
- не записываются в DataStore;
- исчезают при очистке снимков или завершении процесса;
- никогда не входят во встроенный JSON-экспорт.

В экспорте ключи уведомлений и другие идентификаторы хэшируются SHA-256. Хэш изображения относится только к пикселям и размеру питомца.

## Сеть и обновления

Разрешения `INTERNET` и `ACCESS_NETWORK_STATE` используются только механизмом обновления.

Codex Pet обращается к публичному GitHub Releases API репозитория `4erk/codex-pet-android` и, если пользователь разрешил, скачивает APK опубликованной стабильной версии. Тексты уведомлений, диагностические данные, набор питомца и пользовательские настройки в эти запросы не добавляются.

Перед установкой APK из GitHub приложение проверяет:

- HTTPS;
- допустимый размер файла;
- SHA-256, опубликованный GitHub для файла выпуска;
- Android package `com.mr4erk.codexpet`;
- постоянный сертификат подписи production-версии;
- соответствие версии APK выбранному выпуску GitHub.

Тестовая сборка `com.mr4erk.codexpet.debug` может проверить GitHub и установить стабильный `com.mr4erk.codexpet` рядом с собой. Это отдельное приложение Android с отдельными разрешениями и данными. Стабильная версия после первой установки обновляет уже сама себя тем же постоянным сертификатом.

## Ручное обновление из файла

Пользователь может выбрать APK через системный файловый выбор Android. Дополнительный широкий доступ к хранилищу для этого не запрашивается.

После выбора:

- URI используется только для одноразового чтения;
- исходный URI не сохраняется в настройках;
- APK копируется во внутренний кэш Codex Pet с ограничением размера;
- в стабильной сборке принимается только более новая версия того же приложения с той же подписью;
- в тестовой сборке дополнительно можно выбрать production APK `com.mr4erk.codexpet`, но только с закреплённым production-сертификатом.

Ручной APK никуда не загружается. Неподходящие, старые или неподписанные правильным ключом APK отклоняются до запуска системной установки.

Установка и GitHub-, и ручного APK выполняется через системный Android `PackageInstaller` и требует предусмотренного Android подтверждения пользователя. `REQUEST_INSTALL_PACKAGES` нужен только для этих сценариев.

В приложении отсутствуют analytics, Crashlytics, telemetry, ads и trackers. Cleartext traffic запрещён через network security config.

## Неиспользуемые возможности

Приложение не запрашивает широкий доступ к хранилищу, контакты, SMS, геопозицию, камеру, микрофон или `QUERY_ALL_PACKAGES`; не использует Accessibility; не читает приватные файлы ChatGPT; не перехватывает его трафик или токены.
