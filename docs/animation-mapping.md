# Анимации и приоритеты

Статус задачи и выбор анимации решаются отдельно. Progress и `FLAG_ONGOING_EVENT` определяют достоверный статус задачи. Для более точной позы питомца сначала анализируется актуальный текст уведомления на русском и английском; если точного сигнала нет, используется structured status.

## Официальные ряды pet pack

| Ряд | Использование |
|---|---|
| idle | Нет активного состояния |
| running-right / running-left | Drag вправо / влево |
| waving | Открытие bubble и новое сообщение ChatGPT |
| jumping | Однократное успешное завершение |
| failed | Ошибка или потеря связи с удалённым компьютером |
| waiting | Ожидание ответа/разрешения или переподключение |
| running | Активная Codex-работа |
| review | Проверка, тестирование, анализ, готовый результат после one-shot |
| 16 look directions (v2) | Короткий взгляд в сторону открытой панели |

## Приоритет

1. Ошибка или потеря связи.
2. Ожидание пользователя или переподключение.
3. Короткий success-прыжок.
4. Короткая реакция на новое сообщение другого чата ChatGPT.
5. Review/check/test/analyze.
6. Активная работа.
7. Idle.

При нескольких Codex-задачах более высокий приоритет побеждает. Сообщение другого чата вызывает только one-shot и затем возвращает питомца к состоянию Codex-задач. Настройки позволяют отдельно отключить авто-баблы задач, реакции внимания, сообщения других чатов и завершение; по умолчанию всё включено.
