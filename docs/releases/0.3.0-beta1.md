# Codex Pet 0.3.0-beta1

Проверяемая beta для Android 11–16, приоритетно HONOR X9c / MagicOS 9.

## Главное

- Встроен предоставленный Violet Vixen v2 sprite pack: 9 исходных анимаций и 16 направлений взгляда.
- Большая панель заменена одним компактным comic-style speech bubble, привязанным к размеру и позиции pet.
- Реплика использует актуальный `BigText`/`MessagingStyle` notification и по нажатию отправляет исходный task-specific `PendingIntent` ChatGPT.
- Несколько значимых событий циклически отображаются в одном окне без его пересоздания.
- Общий выключатель авто-реплик подавляет все автоматические категории, включая обычные чаты ChatGPT.
- Running живёт до изменения notification; chat/completed — по таймеру; needs-input/error/disconnected — до изменения или удаления notification.
- RU/EN эвристики выбирают исходную sprite-анимацию раньше грубого status fallback. Attention-состояния прерывают менее важные one-shot реакции.
- Добавлен безопасный ZIP import: без распаковки путей, с защитой от traversal, лимитами и декодированием только выбранного atlas.
- Foreground notification получил быстрые действия: pet показать/скрыть, авто-реплики вкл/выкл, следующая реплика.

## Проверка на устройстве

После обновления нажмите «Проверить анимацию». Миграция один раз включает новый sprite animation engine, потому что прежний переключатель управлял удалёнными transform-анимациями.

Если MagicOS сохранил доступы debug-приложения, APK обновит тот же package `com.fourerk.codexpet.debug`. Если доступ к уведомлениям снова заблокирован Restricted settings, разрешите его на экране сведений о приложении и повторно включите listener.
