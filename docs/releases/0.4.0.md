# Codex Pet 0.4.0

Production stabilization release on top of `0.4.0-beta1`.

## Fixed

- Speech bubbles no longer get removed and re-added on every pet drag event. Attached `WindowManager` views are repositioned in place with `updateViewLayout`, eliminating the visible blink and reducing overlay churn.
- Edge snap now moves the same attached bubble windows instead of rebuilding them every animation frame.
- A new touch cancels an in-flight edge snap, preventing the animator from fighting the user's drag.
- Drag animation direction follows the latest horizontal movement instead of the displacement from the initial touch point.
- Content/page rebuilds arriving while the pet is moving are deferred and applied once motion finishes, so live notification updates cannot repeatedly recreate bubbles mid-drag.
- Overlay shutdown now calls `stopService` instead of starting the service again with a hide action.
- Speech placement geometry is isolated in a pure component and covered by unit tests for right/left placement, vertical fallback and safe-bound clamping.

## Release pipeline

- Version promoted to `0.4.0` / versionCode `5`.
- Pull requests and non-main branches build an unsigned minified release candidate in addition to unit tests, lint and debug APK.
- Production signing now requires the complete keystore/password/alias/password secret set. Partial signing configuration no longer produces a misleading release step that fails at signature verification.
- Main builds always produce a release APK. If signing is configured, CI verifies the APK with `apksigner` and uploads the signed artifact; otherwise it explicitly uploads an unsigned artifact.

## Validation gate

The release must pass:

- `testDebugUnitTest`
- `lintDebug`
- `assembleDebug`
- `assembleRelease` with R8/resource shrinking
- `apksigner verify` for signed production artifacts

Manual device smoke coverage should include pet drag with 1–5 visible bubbles, repeated direction changes, edge snap interruption, portrait/landscape rotation, hide/show/stop, notification churn during drag, and a MagicOS/HONOR background/overlay pass.
