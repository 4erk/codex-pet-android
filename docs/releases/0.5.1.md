# Codex Pet 0.5.1

Stable update UX hotfix on top of 0.5.0.

## Manual updates

- Added an explicit **manual GitHub check** that works regardless of the automatic-update switch.
- Added **Install APK from file** for cases where the APK was downloaded separately or GitHub API access is temporarily unavailable.
- The selected file is copied into Codex Pet's private update cache with a hard size limit; the original document URI is not retained.
- Manual APKs must parse as the same Android package, use the exact same signing certificate and have a strictly higher `versionCode` than the installed app.
- Same-version reinstall, downgrade and foreign APK installation are deliberately rejected: this feature is an updater, not a generic package installer.
- Manual and GitHub paths converge on the same Android `PackageInstaller` flow and therefore keep the normal Android user-confirmation requirement.
- Returning from the one-time “install unknown apps” permission screen resumes a prepared manual APK just like a downloaded GitHub update.

## Update screen UX

- Split update controls into clear **Manual** and **Automatic** groups.
- Status now identifies whether the prepared update came from GitHub or a local APK file.
- Busy states disable conflicting update actions while checking, downloading, validating or installing.
- Kept a direct GitHub Releases link as a fallback.

## Verification

Release gate remains:

1. unit tests;
2. Android lint;
3. debug APK assembly;
4. minified/R8 release assembly;
5. production signing with the persistent release certificate;
6. `apksigner` verification;
7. immutable GitHub Release `v0.5.1` with `codex-pet-0.5.1.apk` and SHA-256 checksum.

Version: `0.5.1`, versionCode `7`.
